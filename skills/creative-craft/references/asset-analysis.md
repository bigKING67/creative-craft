# Existing-asset analysis

Creative analysis must distinguish what is present from what the reviewer
believes it means.

## Analysis order

### 1. Inventory

Record:

- file, type, dimensions, ratio, duration, frame rate, codec, audio, language;
- source, version, owner, date;
- placement and intended use;
- performance data and date range, when available;
- rights and consent status.

### 2. Objective description

Describe without evaluation:

- visible subjects, product, environment, text, logo, CTA;
- composition, hierarchy, shot sequence, transitions;
- spoken words, music, effects, silence;
- color, lighting, material, movement;
- first and final states.

### 3. Attention and communication

Analyze:

- first focal point;
- first three-second behavior;
- message order;
- hook;
- proof;
- brand recognition;
- product recognition;
- CTA;
- cognitive or visual competition.

### 4. Craft

Inspect:

- geometry and anatomy;
- product/label fidelity;
- text accuracy;
- masking, edges, reflections, shadows;
- continuity;
- motion and physics;
- lip/audio sync;
- accidental text or symbols;
- compression and delivery defects.

### 5. Interpretation

State likely meaning, mood, audience signal, cultural association, and brand
fit as `INFERRED`, not observed fact.

### 6. Performance hypothesis

Link a hypothesis to:

- observation;
- likely mechanism;
- metric;
- expected direction;
- alternative explanation;
- confidence;
- controlled test.

Do not claim causality from one asset and one metric.

## Decision vocabulary

- `KEEP`
- `AMPLIFY`
- `POLISH`
- `SIMPLIFY`
- `RECOMPOSE`
- `REWRITE`
- `REGENERATE`
- `RE_EDIT`
- `RE_SHOOT`
- `REPLACE`
- `DROP`
- `TEST`
- `DEFER`
- `DOCUMENT`

Every decision should include:

- evidence;
- reason;
- preserved value;
- action;
- validation;
- confidence.

## Review record

Use this structure:

```text
ID:
Asset:
Evidence state:
Observation:
Interpretation:
Opportunity or risk:
Performance hypothesis:
Decision:
Primary change:
Preserve:
Validation:
Confidence:
Remaining unknown:
```

## Comparison

When comparing variants:

- use the same brief and slot;
- normalize viewing conditions;
- state whether the source, crop, copy, duration, sound, or provider changed;
- avoid attributing improvement to one variable when several changed;
- compare actual outputs, not prompts alone.

## Legitimate preservation

`KEEP` is correct when the asset already satisfies the brief, production
quality, rights, and delivery requirements. Novelty is not an automatic
improvement.
